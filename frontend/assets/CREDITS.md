# Créditos de las texturas

- `moon_lroc_4k.jpg`: NASA Scientific Visualization Studio, [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720) (LRO/LROC), dominio público. Convertida de TIFF a JPEG.
- `earth_blue_marble.jpg`: NASA Blue Marble, copia distribuida en los ejemplos de [three-globe](https://github.com/vasturiano/three-globe). No se comparó con el original de NASA.
- `earth_clouds_1024.png`: ejemplos de [three.js](https://github.com/mrdoob/three.js/tree/r160/examples/textures/planets) (r160, repositorio con licencia MIT). No se verificó el autor original de la imagen.
